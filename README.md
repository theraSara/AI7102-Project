# Robust Multimodal Emotion Recognition from Speech and ASR-Generated Transcripts

## Project Overview: Confidence-Gated Multimodal Fusion (CG-Fusion)

This project implements a novel Confidence-Gated Fusion Model (CG-Fusion) to improve the robustness of speech emotion recognition (SER) when relying on error-prone transcripts generated by Automatic Speech Recognition (ASR) systems. Traditional multimodal models often assume perfect text input.

Our approach introduces a dynamic gate that adaptively weighs the Audio and Text modalities based on the ASR's own confidence score ($c$). This ensures that the model can strategically rely on the robust Audio features when the Text (ASR transcript) is deemed unreliable.

### Core Contributions

**Confidence-Gated Fusion (CG-Fusion)**: A trainable gate mechanism that takes the ASR confidence score ($c$) as input to dynamically calculate the weights for audio ($\mathbf{g}_A$) and text ($\mathbf{g}_T$).
$$
\text{Fused Feature} = \mathbf{g}_A \cdot \text{Proj}(\mathbf{F}_A) + \mathbf{g}_T \cdot \text{Proj}(\mathbf{F}_T)
$$

**Dual-Text Mixing**: We utilize both mean-pooled and confidence-weighted text embeddings, blending them via a learned mixer (DualTextMixer) to create an optimized, high-quality text representation ($\mathbf{F}_{\hat{T}}$) before it reaches the fusion gate.

**Comprehensive Benchmarking**: Implementation and comparison against standard baselines, including Early Fusion (Concatenation) and Late Fusion (Weighted Logit Sum).

### Setup and Installation

* Python 3.8+
* The project heavily relies on PyTorch and the Hugging Face `transformers` library for feature extraction.

**Environment Setup:**

git clone https://github.com/theraSara/AI7102-Project.git
cd AI7102-Project

```bash
pip install -r requirements.txt
```

### Data Preparation

A. Dataset
This project uses the IEMOCAP dataset. You must download the raw audio and ground-truth transcripts separately.

B. Feature Generation Pipeline
The models expect pre-extracted, high-dimensional features (e.g., from Wav2Vec 2.0 and RoBERTa) and ASR confidence scores. The complete process is:

1. Generate ASR Transcripts & Confidence Scores: Run `ASR_generation.py` to process the raw IEMOCAP audio files using an external ASR service (Whisper) and save the resulting transcripts and associated utterance-level confidence scores.

```bash
python src/ASR_generation.py
```

2. Extract Features: 

* Use a pre-trained Speech Transformer (`wav2vec2-base-960h`) to extract utterance-level audio embeddings (mean-pooled).

* Extract two sets of text embeddings from the ASR transcripts using a language model (`roberta-base`):

    1. Mean-Pooled Text Features: Simple mean pooling over all token embeddings.
    2. Confidence-Weighted Text Features: Token embeddings are weighted by their individual ASR token confidence scores before pooling.
    ```bash
    python src/feature_extraction.py
    ```

The finak feature files should be organized under the `features/` directory and include the utterance embeddings and ASR confidence scores ($c$).

### Training and Execution

A. Training CG-Fusion (The Proposed Model)

The main fusion model uses the Dual-Text input and the Confidence Gate. 

To train the CG-Fusion model:

```bash
python src/gated_fusion_module/main.py
```

This script will:
    1. Load all pre-extracted audio and dual-text features.
    2. Initialize and train the `GatedFusionModelDualText` using `GatedFusionTrainer`.
    3. Save the best model checkpoints and final evaluation metrics to the `results/` directory. 

B. Training Early and Late Fusion Models

Early Fusion (Concatenation):

```bash
python src/early_fusion_module/main.py
```

Late Fusion (Weighted Logit Sum):

```bash
python src/late_fusion_module/main.py
```

demo_and_analysis.ipynb

This notebook includes utilities for:

* Generating classification reports and confusion matrices for all models.
* Demonstrating the inference of the final trained CG-Fusion model.
